# 生产数据库结构只读核查

DATABASE_SCHEMA 对应中文“数据库结构核查”，是检查受控远程部署 inspect_remote_deployment 的固定任务，不是通用 SQL 工具。参数只能是 task，SSH/EXECUTE/HIGH，沿用 SafeExecutionGateway、一次性参数绑定审批、RunStep、AuditEvent 以及固定生产目标。

用途：在已有网站第一次引入 Flyway 前，先了解真实数据库结构，避免凭源码推测 V1 就直接接管。固定 MySQL 容器只查询 information_schema；凭据留在容器内，不读取业务数据或默认值。完整结构输出经过协议校验计算 SHA-256；超时、失败或截断不产生可用摘要。MySQL 查询、远端进程、SSH 和输出都有限额，不削减之前的备份、构建、审计能力。

结构采集成功不等于结构兼容，也不等于基线登记或发版成功。只读事务不能冻结并发 DDL，后续登记必须重新核查并绑定备份/候选。Flyway 接管使用显式审批，不允许自动 baseline-on-migrate，不允许任意 SQL。应用回滚不自动覆盖数据库。
