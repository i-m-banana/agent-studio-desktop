# 受控远程工作台人工验收

## 当前口径

本阶段已完成自动化测试、前端生产构建和真实界面/SSH 工作台人工验收。用户于 2026-09-19 确认多项固定任务运行通过，文件浏览无需等待 Agent、父目录导航和操作助手内部滚动均符合预期。本记录没有取得具体运行 ID，因此不虚构逐条运行证据；完整运行仍以应用中的运行记录与 AuditEvent 为准。

## 前置条件

1. 使用已验证的 SSH 工作区配置和固定 SHA-256 主机指纹；
2. 如需执行补丁或固定任务，发布一个包含 `apply_remote_workspace_text_patch`、`run_remote_workspace_task` 的 AgentVersion；仅浏览目录和文本不需要 Agent；
3. 远程根内保留 Git、Maven 和 npm 三个可信测试项目；
4. 不使用生产部署目录，不修改 `manual-acceptance/`。

## 界面验收

1. 打开“远程工作台”，确认左侧为文件区、中间为标签工作区、右侧为 Agent/审批区；
2. 确认顶部目标与底部状态栏显示当前 SSH 目标和授权远程根；
3. 确认 Agent 下拉框只列出包含远程工具的已发布版本；
4. 连续执行多次操作，确认整个工作台高度固定在视口内，左侧文件、中间内容和右侧助手分别内部滚动；
5. 确认右侧只突出当前运行步骤和最近消息，更早消息收起且可在运行记录查看；
6. 在窄窗口检查三栏依次折叠，页面不产生不可恢复的横向遮挡；
7. 确认部署标签明确标记尚未接入，不能触发 Docker/Nginx 操作。

## 文件验收

1. 不选择 Agent，打开远程工作台，确认根目录自动出现在左侧文件树且没有创建 AgentRun；
2. 点击普通 UTF-8 文本，确认不等待模型，中间直接显示路径、行号、大小、SHA-256 和只读内容；
3. 进入一层或多层子目录，使用“↑ 上级”逐级返回；确认根目录时按钮禁用，且请求中不使用 `..`；
4. 输入 `..`、绝对路径、符号链接路径和受保护文件，确认后端拒绝；
5. 确认 `.env`、私钥、凭据目录不出现在文件树中；
6. 确认页面没有直接保存文件按钮，补丁仍必须由 Agent 工具和 HIGH 审批完成。

## 固定任务验收

分别在可信项目目录请求 `GIT_STATUS`、`GIT_DIFF_SUMMARY`、`MAVEN_TEST`、`NPM_TEST`、`NPM_BUILD`：

1. 点击任务卡后，右侧出现 AgentRun 步骤；
2. HIGH 审批卡显示固定工具、SSH 目标、相对 path、task 和参数摘要；
3. 批准一次后，中间“输出”显示 successful、exitCode、duration、目标和截断状态；
4. 拒绝一次，确认没有 SSH Exec 启动；
5. 非零退出码作为完成结果显示，而不是连接失败；
6. 页面中不存在命令、参数、环境变量或 Shell 输入框。

## 目标变化验收

1. 发起任一 HIGH SSH 任务并停留在审批卡；
2. 在另一窗口改变 SSH 主机、端口、用户名、远程根或主机指纹；
3. 返回原审批并批准；
4. 确认工具不执行，运行失败信息指向目标变化；
5. 在运行审计中确认存在 `TOOL_TARGET_CHANGED/REJECTED`，不存在对应的 `TOOL_EXECUTION_STARTED`。
