# SSH/SFTP 远程只读工作区人工验收

## 准备

1. 只使用测试服务器或隔离账户，不要先连接生产环境。为账户限定一个不含真实密钥的项目目录，并确认它没有读取其他目录的权限。
2. 在 Agent Studio 之外核验服务器主机公钥指纹。服务器通常同时存在 ED25519、ECDSA、RSA 等多把主机密钥，必须比较同一种算法；可在服务器执行 `for f in /etc/ssh/ssh_host_*_key.pub; do ssh-keygen -lf "$f" -E sha256; done` 列出全部算法和指纹。不要根据 Agent Studio 报出的“实际指纹”直接信任未知主机。
3. 打开“模型配置”页面下方的“SSH 远程工作区”，填写服务器公网 IP/域名、端口、用户名和远程项目绝对目录。点击“检测指纹”，再把结果与第 2 步的独立可信结果核对；一致后保存。
4. 在同一表单填写测试账户密码。连接信息写入本机业务数据库，密码写入 Windows DPAPI 安全存储，接口和页面不会回显。环境变量仍可作为部署覆盖方式，但人工验收不再要求先配置环境变量或重启应用。
5. 点击“测试 SSH/SFTP 连接”，确认状态变为 READY。然后新建或编辑 Agent 草稿，绑定三个 `SSH` 来源工具并发布新版本。

## 正向主链

依次向绑定后的 Agent 提问：

1. “调用 `list_remote_workspace_directory` 浏览远程工作区根目录，最多返回 30 项。”
2. “调用 `search_remote_workspace_files`，搜索文件名或路径包含某个真实类名的文件，不指定 path。”
3. “调用 `read_remote_workspace_text_file` 读取刚才找到的文本文件第 1 到 30 行。”

确认返回中包含准确的 `target`、相对路径和读取文件的 SHA-256；运行详情应出现 MODEL_CALL、TOOL_CALL、TOOL_RESULT，安全审计应记录请求校验、开始和完成。三个工具是只读低风险工具，不出现写入审批。

## 负向边界

1. 请求读取 `../outside.txt`，应在建立文件读取前拒绝路径越界。
2. 请求读取 `.env`、`.ssh/id_rsa` 或私钥后缀文件，应提示路径受保护。
3. 在远程根目录创建指向根外的符号链接后请求读取，应拒绝符号链接路径。
4. 临时把配置指纹改成错误值并重启，任何远程工具都应失败并明确提示主机指纹不匹配；恢复已独立核验的正确指纹。
5. 停止 SSH 服务或填写错误密码，调用应在连接预算内失败，RunStep 和 AuditEvent 不得显示成功。

## 通过口径

记录三条正向运行 ID、至少一条负向运行 ID 和测试服务器环境。本清单通过只代表“固定指纹、单目标、密码认证的 SSH/SFTP 远程只读工作区已验收”，不能据此声称远程命令、配置修改、日志命令、代码写入、构建测试或部署已经完成。

## 真实验收记录（2026-09-15）

测试目标为 Ubuntu 24.04 服务器上的受限根目录 `/root/zzh`，AgentVersion 为 `42f827a5-7030-41c0-b4e1-6dd6992f1696`。用户确认三次前向测试和两次反向测试均符合预期：

- `b8edbcb9-bcd4-47e6-9872-08702dcd0f06`：列出远程根目录，返回 `zzh-vue`，SFTP 工具与三条审计事件完成；
- `60767fb6-3206-4959-b386-0d6e1f74b947`：根目录搜索 `helloworld`，扫描 62 项、跳过 1 项，找到 Vue 组件及测试文件，未截断；
- `44a6c0d4-08ff-4bde-b1f5-4a8baf6d4671`：读取 `HelloWorld.vue` 前 30 行，返回 687 字节、42 行、完整文件 SHA-256 和正确截断标志；
- `6dc7b118-6e43-4e78-b4df-81711950c60f`：请求授权根外的绝对路径时，模型识别工作区边界并在调用工具前拒绝；因此该条没有 TOOL_CALL/AuditEvent，工具层越界拒绝仍由自动化测试证明；
- `e6ac26e2-cc66-49e7-95e2-af2ad38e9509`：配置不匹配指纹后，真实工具调用形成 FAILED TOOL_RESULT 和 TOOL_EXECUTION_FAILED 审计，未建立获信任的 SFTP 操作。

补充运行 `0fd23a86-17c3-4c63-98eb-e92f07f38375` 成功列出远程 `zzh-vue` 子目录。结论：固定指纹、单目标、密码认证的 SSH/SFTP 远程只读主链已完成自动化与真实服务器/模型验收。
