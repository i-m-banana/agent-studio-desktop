# UI优化收尾

按用户最新要求，不再单独开发3B、3C、3D。此次补齐四项使用需求，结束本次UI优化。改动已在本地运行，尚未提交。

## 已完成

1. **助手归档与恢复。** 助手卡片增加“归档助手”；默认清单和新会话版本选择隐藏已归档助手。筛选“已归档”后可恢复。已有会话、发布版本、运行记录保持原样；归档助手不能创建新会话或编辑发布，打开已有会话仍可查看和继续。
2. **长任务反馈。** 独立浮动面板显示后台阶段、当前工具、已等待时间和最近确认时间。每两秒向后台确认一次；连接异常显示“暂时无法确认”，不显示虚构进度。用户可以停止运行；提交后显示停止中，已完成操作不会撤销。
3. **审批始终可见。** 审批从消息滚动区移到全局固定面板。保留原参数、目标、摘要、剩余时间与批准/拒绝按钮；跨页面、长消息和窄屏都能看到。只恢复当前有效的待审批请求，不复用已处理或历史审批。
4. **发布记录移到07。** 历史菜单只管理聊天。原“更多选项与发布记录”用于查看发布阶段、回执与审计，以及选择其他会话的候选材料；现集中在“07运行记录 → 发布记录”。记录默认收起，展开后可跳转到来源运行与审计。选择候选只改变远程工作台的材料来源，不自动执行操作。

## 简短查看说明

| 做什么 | 应该看到什么 |
|---|---|
| 在04助手管理，对不需要的助手点击“归档助手”。筛选“已归档”。 | 常用清单不再出现它；归档清单提供“恢复助手”。旧聊天仍可打开。 |
| 下次正常执行较长任务时，看屏幕右下角。 | 能看到当前状态、等待时长、后台确认时间和停止按钮。 |
| 下次需要审批时，滚动聊天或切换页面。 | 审批面板留在屏幕上，批准和拒绝按钮仍能看到。 |
| 打开历史管理，再打开07中的“发布记录”。 | 历史管理只剩会话；发布记录可展开详情，并查看来源运行。 |
