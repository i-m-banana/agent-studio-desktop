## 用来做什么

开发后、正式发布前，先看到真实模板渲染的页面，检查筛选、按钮、空结果和布局。预览使用本次批准的源码副本和合成数据，操作不会影响线上网站。验收通过后，仍按原发布链路准备候选、备份和审批上线；预览不会替你上线。

不是完整的生产环境仿真：使用 H2，不是 MySQL；没有运行网站三个 Testcontainers `*IT`。Flyway 在这个视觉预览配置中关闭，按网站已有 H2 结构初始化，不能据此认定生产迁移或数据库兼容性通过。原测试与发布能力没有被删减。

## 首次使用

1. 在 **04 助手管理** 编辑本地代码助手，勾选中文工具 **“启动受审网站隔离预览”**，发布新版本。旧版本不自动获得新工具。
2. 在 **06 对话测试台** 选择这个新版本，新建会话，点击工具栏 **“选择项目”**，选择“时光序”。项目须已经确认真实数据保护范围。已有会话不换项目。
3. 点击 **“项目：时光序” → “网站隔离预览” → “请求启动预览”**。亦可直接说：“请启动当前项目的网站隔离预览，只使用合成数据，不连接生产。”
4. 核对审批卡中的项目、源码目录、源码 SHA-256、固定验证镜像、断网与合成数据说明，然后批准。会先断网运行测试及打包；失败不会启动网站，去运行记录查看失败原因。首次准备需要等待，不能重复点击。
5. 工具真实回执应为 `successful:true`、`state:READY`，含本机地址及源码摘要。重新打开项目面板，点击 **“打开预览”**。地址只在本机有效，形如 `http://127.0.0.2:随机端口`，不应填到生产健康地址中。
6. 验收结束点 **“停止并清理本次预览”**。应显示已停止，原地址不可访问。正常运行到期约 30 分钟自动停止；源文件又改了，旧页面仍是旧快照，需停止并重新请求。

不要求你填数据库、端口、命令、文件路径或容器参数。首版全局最多一个实例；另一个项目已有预览或清理未确认时必须先处理原实例。

## 本次筛选优化如何验收

| 操作 | 预期 |
| --- | --- |
| 打开 `/browse` | 有合成条目，不是生产内容；生产网站没有变化 |
| 选择主题“旧”、标签“童年动画”，搜索“测试” | 当前筛选区显示这三个实际条件，结果有“预览测试：童年记忆” |
| 点“清除搜索” | 关键词被清除，主题、标签和排序保留 |
| 点“重置筛选” | 关键词、主题、标签清除；当前页签和排序保留 |
| 搜索不存在的词 | 出现空结果说明，不是异常页 |
| 用临时虚构账号注册后访问收藏页 | 可访问；在收藏/候选页重置仍保留页签，不使用真实账号或密码 |
| 缩窄浏览器窗口 | 检查筛选条是否换行、按钮是否可点、有无横向溢出；这是人工验收项 |
| 停止预览 | 地址失效；本次容器、卷与源码快照回收，源目录不改动 |

外部字体/图片/CDN 访问被关闭，合成数据不含真实附件，因此字体和附件展示不与生产完全一致。不支持 WebSocket、流式请求或大文件上传；请求上限 1 MiB、单个响应 4 MiB，最多四个并发转接请求。

## 安全边界与产物

- 工作容器保持 `network=none`；平台只把 HTTP 请求转接到容器内部固定 `127.0.0.1:3000`，没有给工作容器开放宿主数据库、网络或 Docker socket。
- 浏览器入口绑定 `127.0.0.2`，与 Studio 的 localhost 来源分离；校验 Host/Origin，浏览器策略禁止外部连接、跨来源表单和嵌入。
- 审批绑定项目及源码摘要。等待批准期间源文件变动会拒绝执行；不允许模型传入任意启动命令或数据库地址。
- 构建与网站运行有限制内存、CPU、进程数，容器根只读；构建镜像按既有固定 SHA-256 使用，不在线拉取依赖。
- 本次快照在 Windows 临时目录 `agent-studio-source-*`；本次网站 JAR、临时上传和运行目录在专用 Docker 卷 `agent-studio-preview-UUID`。H2 数据在内存中，不写到业务数据库。不会向业务源码根生成本次 target。
- 状态存在 Studio 自己的 `local_preview` 表，运行/审批仍进入既有记录；刷新可再次打开项目面板读取状态。重启不自动恢复执行，只回收原资源。容器本身也设置了 30 分钟退出限制，避免后端意外退出后无限运行。
- 停止、启动失败及到期清理只针对匹配名称和归属标签的资源；不会做全局 Docker 清理，不删生产备份、镜像、源代码或其他容器。清理失败显示“待回收”，保留记录并禁止再次启动，需要重试停止，不能当作没有副作用。
- 暂未提供独立磁盘配额；Docker 资源和临时快照短暂占用空间，须保持足够可用空间。停止回收逻辑不能保证 Docker Desktop 内部虚拟磁盘文件立即缩小。
