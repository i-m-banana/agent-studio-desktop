## 环境与范围说明

验证镜像固定为已准备的 SHA-256 镜像 ID，使用明确的本地 Docker 引擎。离线依赖缓存按当前工具链准备；项目需要不同依赖时应先更新可信缓存，缺少依赖时会失败，不会自动开放网络。

缓存准备清单现包含平台 Spring Boot 3.4.3 与网站所需 Spring Boot 3.2.5 / Java 17、Testcontainers 1.21.4 等公开依赖。平台维护独立样例 POM，通过 Maven Central 下载并执行样例测试、打包及离线复核；不复制业务 POM 中的自定义脚本、仓库、凭据或业务源码到联网准备阶段。真实项目的验证仍关闭网络。新依赖不在缓存中时，需要再次审查并更新清单。

补充验证：4 项真实容器检查通过，包含 Spring Boot 3.2.5 样例的断网测试与打包；宿主样例目录没有生成 target。另有 14 项工具与错误分类回归、37 项前端测试通过，前端构建通过。缺少离线依赖时返回 `DEPENDENCY_CACHE_MISSING` 并显示环境准备提示，保留原始失败状态和日志。没有据此宣称业务网站测试通过。

容器限制 CPU、内存和进程数；临时构建卷尚无独立磁盘配额，需关注 Docker 存储空间。保护边界针对 Agent Studio 的工具和隔离验证，不代替对同一 Windows 账户下其他程序的操作系统权限控制。

新建文件当前只覆盖已有目录中的源码 / 测试文本；不开放任意脚本、配置文件、二进制或任意目录创建。真实数据库联调和线上验收仍需明确的测试数据及部署配置。
