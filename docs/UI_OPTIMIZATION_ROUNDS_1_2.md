## 各页面的变化

| 页面 | 现在的默认界面 |
|---|---|
| 模型配置 | 显示已有模型。新增模型、服务器连接和安全凭据按需展开；服务器写入与执行的说明已修正。 |
| 知识库 | 紧凑的新建、上传入口。知识库选择与文档清单放在一起；文档状态用中文显示。 |
| MCP 连接 | 显示已有连接和编辑、测试按钮。连接参数、工具权限、同步记录、资源和提示词收起；导出、停用和删除放在“更多操作”。历史同步成功不会被写成当前调用已经测通。 |
| 助手管理 | 原 Agent Builder 改为“助手管理”。创建/编辑表单默认收起，编辑时直接展开。工具名称使用可读名称，详细权限和说明按需查看；列表卡片更紧凑。 |
| 对话测试台 | 先显示消息，运行步骤和检索来源放在消息后并收起；当前待审批操作仍单独显示。固定工具请求和回执优先显示简短摘要，原文可以展开。 |
| 远程工作台 | 移除“变更”占位标签和无助于操作的数字展示。文件栏、助手栏可收起；窄屏直接切换工作区、文件栏和助手，不再将三块内容堆成很长的页面。 |
| 远程部署 | 下一步单独显示。已完成准备步骤收起，待处理步骤展开；首次数据库登记与日常发布分开。原证据有效期、参数绑定、风险确认和一次性审批保持原规则。 |
| 运行记录 | 已结束与操作成功分开表达。详情先显示结论，完整步骤、版本时间和安全审计按需展开；长列表在自身区域滚动。 |
| 系统诊断 | 状态和说明更直白。区分密钥已配置、上次同步成功和实际环境检查，不把历史连接信息当作新的测试。 |

统一缩小页头与导航，提高主要文字和操作的可读性，统一按钮、折叠入口、输入框、焦点和危险操作的样式。浮动通知继续自动消失，不占用正常布局。

## 同时修复的现有交互

- 中文输入法确认文字不会触发发送；Shift+Enter 保留换行。
- 恢复会话后仍在运行的任务，可以使用原有停止按钮。
- 快速切换会话、知识库和运行记录时，较晚返回的旧请求不覆盖新选择。
- 切换会话后，不再残留上一段会话的固定任务输出。
- 部分页面资料读取失败不会直接显示“整个后端未连接”。
- 配置失败原因保留在对应表单内；浮动提示关闭后仍可查看。
