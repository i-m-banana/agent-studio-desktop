# 第三轮首批：搜索、取用与阅读

上一轮已由用户验收，提交为 `1c185d2`，位于 `feat/ui-simplification`。本批改动尚未提交，供用户查看。

## 本批完成

- 助手、工具和文档清单增加搜索；助手、文档和运行记录增加状态筛选。
- 历史管理支持正文搜索，普通会话与已删除会话分开查找；每次加载50条，可继续加载更早记录。
- 运行记录支持搜索与分页，标题对应本次任务的提问，显示助手名称。
- 消息、代码、文档当前页、远程文件当前段和任务输出可以复制。
- 会话可导出Markdown；运行详情可导出包含步骤与审计的JSON。
- 聊天可定位最新消息。阅读旧消息时，新内容不强制改变阅读位置。
- 知识库文档可阅读提取的文字并分页。远程长文件可前后翻段、输入行号后按回车跳转。

## 检查结果

- 后端162项测试通过，前端32项测试通过，生产构建通过。

- 真实页面验证：运行记录从50条加载到100条；按编号找到第一页之外的超时任务；已删除清单按正文找到较早会话。

- 远程已有9312行文本文件只读验证：1–200 → 201–400 → 1–200，并跳转到601–800行，下一段从实际结束行之后开始。

## 查看时只需三步

| 做什么 | 应该看到什么 |
|---|---|
| 打开“历史会话 → 管理”，输入以前聊天中的关键词；也可以切到“已删除”。 | 只显示匹配会话；已删除会话不会混入正常会话。 |
| 打开知识库，搜索文档，点击“阅读”；在聊天消息旁点击“复制消息”。 | 可以看文档文字，复制后按钮短暂显示“已复制”。 |
| 打开运行记录，选择状态并搜索；打开远程长文件，点击“下一段”。 | 找到对应任务；文件行号连续，可翻回上一段。 |

下载补充检查：在日常浏览器点击“导出会话”或“导出原始记录”，应下载对应Markdown或JSON文件，保留原文与版本身份。
