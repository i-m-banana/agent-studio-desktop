# 远程备份隔离恢复演练人工验收

## 当前口径

固定隔离恢复演练工具、工作台入口、自动化测试和真实生产服务器正向验收均已完成。可以写“隔离恢复材料演练已人工验收”，但不能写“数据库已恢复”“生产恢复已验证”或“可以自动回滚生产”。

## 执行前

1. 确认部署 Profile 为 READY，备份根中至少存在一个由平台成功创建且没有 `FAILED` 的备份；
2. 确认服务器磁盘至少还有 1 GB 可用空间；
3. 发布包含“演练受控远程备份恢复”（`verify_remote_deployment_backup_restore`）的新 AgentVersion；
4. 确认工具为 `SSH/WRITE/HIGH`，Schema 没有 backupId、path、command、参数、环境变量、生产恢复或删除字段。

## 正向验收

1. 在“远程工作台 → 部署”点击“请求恢复演练”；
2. 核对审批目标末尾包含 `RESTORE_DRILL:LATEST_ISOLATED`，参数固定为 `{}`；
3. 批准一次，确认结果选择第二次备份 `20260921T143308Z-5b8b3432` 或当时更新的最新合格备份；
4. 确认返回全新 `restore-...` 演练 ID、固定 `restore-drills` 路径、非零数据库大小、uploads 展开大小、文件数量和两份摘要；
5. 确认结果明确显示“生产目录未修改、数据库未导入”；
6. 在服务器只读核对演练目录权限、`.env` 权限 0600、`drill.sha256`、数据库非空及 `deployment/data/uploads` 存在；
7. 再运行一次只读部署诊断 `COMPOSE_STATUS` 和 `SITE_HEALTH`，确认线上服务仍正常。

## 负向与边界验收

1. 拒绝审批，确认没有新增演练目录；
2. 尝试要求指定旧 backupId、生产路径、数据库名、Compose 命令、删除或覆盖选项，确认执行前拒绝；
3. 自动化覆盖缺少合格备份、摘要或目标不一致、磁盘余量不足对应的非零结果、超时关闭和危险参数拒绝；真实服务器不主动损坏备份制造失败；
4. 确认 RunStep、AuditEvent 和页面不显示 `.env` 内容、数据库密码或 Token；
5. 不执行数据库导入、生产目录替换、容器启动/停止、发布、回滚或清理。
