# ADR 0004：版本化 Ollama 语义向量

- 状态：已接受
- 日期：2026-09-02

## 决定

生产 RAG 默认使用本机 Ollama `qwen3-embedding:0.6b` 生成 1024 维向量。通过 `EmbeddingGateway` 隔离生成方式，`LocalHashEmbedding` 继续作为 `local-hash` 回退实现。

Qwen 向量写入独立的 `knowledge_chunk_v2`，记录 `embedding_model` 和 `embedding_version`。首个版本为 `qwen3-0.6b-v1`，不会与旧 `vector(384)` 数据混用。知识库提供显式重建 API 和前端入口；应用启动不会自动重建或删除用户索引。

1024 维索引当前使用精确 cosine 排序，只建立知识库与版本范围索引。现阶段语料量小，不用 HNSW 牺牲召回换速度；数据规模增长后再通过真实评测决定近似索引参数。

## 证据

冻结题集包含 24 道可回答题和 6 道无答案题。加入安全执行网关材料后的知识包（11 份文档、32 个 chunk，SHA-256 `954f15a497955490510433e99c0878eb21df9975dba56644a506648f6aabb482`）同语料复测中，LocalHash 的 Recall@5 为 79.17%、MRR 为 0.6333；Qwen 无查询前缀时 Recall@5 为 100%、MRR 为 0.8542，改写题 MRR 从 0.5583 提升到 0.8056，本机 p95 约 245 ms。Qwen 仍有收益，但无答案误召回率仍为 100%，后续需评估结构化切块、rerank 和相关性判别。

曾尝试给查询统一添加中文检索指令。在知识包扩充前的同一冻结语料消融中，Recall@5 保持 100%，但 MRR 从 0.8160 降到 0.6917，因此查询指令保留为配置项、默认关闭。该结论来自本项目语料，不推广为所有 Qwen 使用场景的通用结论。

## 边界

Qwen 对当前 6 道无答案题仍有 100% 误召回。阈值扫描显示，提高固定阈值会显著损害 Recall，因此本阶段不宣称解决拒答；后续用独立开发集研究相关性判别、分数间隔、rerank 或回答阶段证据充分性判断。
