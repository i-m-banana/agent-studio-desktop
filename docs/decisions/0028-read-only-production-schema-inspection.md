# ADR 0028：生产数据库结构只读采集

## 状态

2026-09-29 已实现；真实模型/服务器正向验收通过，运行35dff08a-dbf9-4e1e-ac92-a5ebf65a5f90。基线登记见后续ADR0029（仅自动化），不宣称完整发布链路完成。

## 决策

在既有 inspect_remote_deployment（检查受控远程部署）内增加 DATABASE_SCHEMA（数据库结构核查）固定任务，不再拆出通用 SQL 工具。复用 SSH/EXECUTE/HIGH、参数绑定一次性审批、固定生产 Profile、主机指纹、同会话 SFTP 路径检查及既有 RunStep/AuditEvent。模型只能传 task；SQL、数据库名、凭据、路径和选项均不可传入。不增加执行 API 或 MCP Server。

平台固定 SQL 从 mysql 容器自身 MYSQL_DATABASE 选择数据库，MYSQL_ROOT_PASSWORD 仅在该容器内部转为 MYSQL_PWD；平台不打开或返回宿主 .env 内容，Compose 自身可能按正常规则加载该文件，不把密码放到 mysql 命令行或返回值。使用固定 mysql 容器 socket，不向桌面开放数据库端口，不启动/重启服务。元数据包括数据库名/版本、表/视图类型、列类型/可空性/字符集、索引、主键/唯一/外键及外键规则、触发器/例程的存在信息；不读取业务行、列默认值、例程/触发器正文或 Flyway 历史行。

MySQL 会话以只读事务执行，单条查询 15 秒上限；远端 timeout 25 秒/TERM 后 2 秒 KILL，SSH 命令预算 30 秒，工具预算 45 秒。SSH 超时/中断关闭通道。stdout/stderr 合并；普通非零退出仍为可审计结果。结构输出上限 48000 字节，其他诊断保留 16000；有界流的未截断 UTF-8 合并后统一解码，避免中文跨缓存边界损坏。

后端校验 JSON 行宽度、首尾协议边界及标量字段，完整且退出 0 才计算规范 JSON SHA-256。截断/非零结果不产生 schemaSha256；无效协议为工具失败。结构摘要包括数据库名和服务器版本，不包含业务数据；数据变化不应改变摘要，DDL 变化应改变摘要。结果只表示结构采集完成，不代表与 V1 相同或安全发布。

## 边界与后续

只读事务不锁定并发 DDL，也不构成整个 information_schema 的原子快照。本任务没有防篡改签名，不检查用户授权配置、CHECK 表达式/生成列表达式/函数索引表达式等完整语义，不可代替生产结构审阅或隔离恢复验证。触发器/例程/视图的存在会进入摘要，但自动接管必须另行处理，不据此默认兼容。

真实结构输出核对后，再实现独立 HIGH 基线登记：绑定结构摘要、候选材料、新鲜备份与当前目标，在登记时重新采集并拒绝漂移，使用网站 Flyway API 登记、不手写伪历史、不自动 baseline-on-migrate、不执行用户 SQL。之后才能启动新版本；应用回滚依旧不能自动恢复数据库。当前未开放数据库写任务，也未直接连接生产验收。
