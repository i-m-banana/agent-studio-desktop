# ADR 0032：发布阶段任务与历史恢复

2026-10-01。首批实现，自动化与开发者只读核验后交用户验收；不触发生产发布。

## 决策

发布阶段需要独立业务身份。V16在平台本机MySQL增加release_task，每次原子工具TOOL_CALL拥有稳定UUID、唯一source_step_id、runId、conversationId、AgentVersion、toolCallId、工具名及原始创建时间。RunRepository在同一本地事务写入RunStep与任务身份；任务先于工具进入网关创建。它是单步任务，不是已经完成的全链路工作流；后续一键编排应新增有明确成员关系的工作流聚合，不能按相邻时间或同会话猜测多个候选属于一次发版。

原始参数、回执、审批与审计仍以现有持久化源记录为准，不复制一套可被浏览器或LLM修改的成功状态。ReleaseTaskService将同一toolCallId的结果、审批与参数摘要及调用时间区间匹配的AuditEvent投影为业务状态；现有审计无toolCallId，跨调用区间的相同参数审计不得串用。成功要求原始JSON与匹配的批准、执行完成审计；会话COMPLETED或模型消息不能证明成功。缺少/截断JSON、审计不完整、启动后中断且已有执行开始都保守显示UNKNOWN；拒绝/过期跳过为NOT_EXECUTED。上线区分DEPLOYED、RESTORED、MANUAL_INTERVENTION；旧镜像回执虽报告成功但缺少后来新增的RUNTIME_SMOKE时标INCOMPLETE_EVIDENCE，保留原successful=true，不改写为当时构建失败，也不能用于当前上线。

RunRecoveryService先关闭遗留运行和待决审批，再幂等回填过去的TOOL_CALL业务身份。只补本地索引，不修改旧RunStep、审批、回执或审计，不调用工具、不连接生产执行命令、不删除产物。已有缺失证据不能回填成成功。

新增GET /api/conversations（有界分页）、GET /api/conversations/{id}（完整消息与运行）、GET /api/release-tasks（有界分页、可按会话筛选）。没有新增执行API。对话继续走原chat/stream、不可变版本、ToolRegistry、SafeExecutionGateway与一次性参数/目标审批。单实例中在接收消息时同步检查并创建运行，同一会话有活跃任务返回409，避免刷新/多标签重复发送；多实例租约不在本批。

## 恢复语义

浏览器只存会话ID、候选任务ID与界面位置；消息、身份与结果重新从本地后端读取。历史会话恢复原AgentVersion，已归档版本只能继续既有会话，不能开新会话。新会话保留历史资料。远程助手可展开完整消息，技术JSON默认折叠。

默认阶段证据只来自所选会话和当前目标。选择其他会话的候选是显式行为，展示来源时间、目标、运行和原始回执；仅允许候选ID、清单摘要、目标一致的镜像记录与其关联。未知的新构建尝试仍按请求身份使旧成功镜像失效。证据时间取原RunStep结果时间，不以刷新时间或原运行开始时间延长有效期。备份30分钟、结构/历史/线上身份5分钟规则及远端重验保持。超过30分钟的备份是过期证据，不是可删除产物。

同目标历史版本1登记成功或版本历史明确含BASELINE的已审计事实仅用于禁用重复登记，不混入新会话审批参数，也不替代本次新鲜只读检查。历史上线回执说明当时的结果，不能把批准的上线前productionSha256当作当前文件指纹。当前网站状态必须新读取。

恢复运行中任务只轮询展示原运行，发送/切版本禁用；不重放请求、不附着执行线程、不自动批准。刷新前的待决审批不会以历史卡重新提供批准按钮；原待决审批继续受现有有效期约束，原页面仍可操作或到期停止。重启后审批过期、运行中断，不续跑。用户之后的高风险新任务必须重新取得证据并新审批。

## 边界

本批保留所有原子工具、预算、RAG/MCP、迁移/摘要/测试与资源限制。没有生产数据库改动、基线登记、发布、故障注入或服务器清理；平台本地V16与生产网站Flyway版本1是两套数据库。失败副作用与原始回执保留，MySQL DDL不随应用恢复撤销。真实故障恢复仍非已验收能力。用户manual-acceptance/和使用问题.txt不改、不删、不暂存。

## 2026-10-02：紧凑入口与可恢复删除

历史选择移入对话工具栏和远程工具栏。全站共用通知采用固定浮层，6.5 秒自动关闭，不占文档流；运行观察轮询不重复播报成功通知。V17 在本地平台 MySQL 的 conversation 表增加 deleted_at；删除/恢复支持 1–200 个会话，事务保证批量全成功或全撤销。活动运行阻止删除。单实例内共享会话锁串行化新运行建立与删除，沿用当前单实例边界。

普通历史清单、会话读取和继续聊天排除已删除会话；已删除清单可恢复。消息、运行步骤、release_task 和审批审计原文不物理删除，原发布证据仍可用于阻止重复基线登记。界面删除当前会话时清除本地选择与临时消息；跨会话候选选项只提供已加载的未删除会话。没有永久删除或自动清理服务器产物。删除不会减少数据库占用，它用于整理日常聊天清单。
