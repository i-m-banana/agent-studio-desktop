# ADR 0015：受控只读 Coding 工作区

## 背景

`v1.0.0` 明确没有通用 Coding 能力。下一阶段先交付最小只读能力：浏览目录、按文件名或相对路径搜索、读取 UTF-8 文本。生成补丁、应用补丁和运行构建/测试会产生新的副作用，不能混入本阶段。

## 决策

工作区只有一个由 `AGENT_STUDIO_CODING_WORKSPACE` 指定的本机根目录。模型参数只能使用根目录内的相对路径。三个工具作为普通 `AgentTool` 注册到既有 ToolRegistry，能力统一为 `READ/LOW`，调用继续经过 SafeExecutionGateway、RunStep 和 AuditEvent，不增加直接文件 API 或旁路执行器。

共享的 `CodingWorkspace` 在每次访问时检查根目录和目标的真实路径，拒绝绝对路径、`..`、冒号/Windows 数据流、符号链接路径、解析后逃逸、`.git`/`.ssh`/`.gnupg`/`.aws`、`data/secrets`、真实 `.env` 和常见私钥/密钥库文件。`.env.example` 作为公开配置模板允许读取。

目录浏览只返回直接子项，默认 100、最多 200。文件搜索只匹配名称或相对路径，不搜索内容，不跟随链接，最多扫描 10000 项、深度 30、返回 100 项。根目录搜索默认剪枝 `node_modules`、`target`、`dist`、`build`、`out`、`coverage`、`.idea` 和 `.run`；显式把其中一个目录作为搜索起点时仍可访问。收集到 `maxResults + 1` 个匹配后立即停止并标记截断，不为轻量文件定位引入持久索引。文本读取只接受不超过 1 MiB 的严格 UTF-8 普通文件，拒绝 NUL 二进制内容，单次最多 500 行并把输出限制在 16000 字符以内，避免无界模型上下文和 RunStep 膨胀。

## 结果与边界

这使 AgentVersion 可以快照绑定三个只读 Coding 工具，并保留正式版的授权、超时、取消、步骤与审计语义。AuditEvent 仍只保存参数摘要和输出长度，不复制文件内容；RunStep 继续保存模型可见的工具输入与结果，这是两类记录原有的职责边界。

本决策不包含文件内容搜索、Git 语义、补丁生成/预览/应用、写文件、删除、命令执行、构建测试、SSH/SFTP、OS 沙箱、多工作区或工作区页面配置。只有完成人工清单后，才能把真实浏览器/模型链路标为已验收。
